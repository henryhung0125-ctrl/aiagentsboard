This week's top AI agent tools

The top AI agents, ranked weekly

Method: GitHub repos related to AI agents, created after 2026-09-15, sorted by stars (GitHub Search API, read 2026-11-02). Stars show popularity, not quality.

#1

yetone/magpie

Who it's for: Developers who use several coding agents (Claude Code, Codex, Gemini CLI, OpenCode).

What it does: Lets each agent run on another model (e.g. Claude Code on Kimi, Codex on DeepSeek), switched from the menu bar; a local gateway moves to your next account when a quota runs out.

Example: when your Claude Code quota runs out, magpie switches to your next account and you keep working.

★ 28,359 GitHub stars · created 2026-09-23 · summarized from the repo README
#2

browser-use/jev-ultrafast

Who it's for: Developers who want to automate websites with code.

What it does: Give it a goal and the agent picks actions (click, type, select, scroll) from a table of page elements; the README cites a Google Flights search done in 7.1 seconds.

Example: ask “find flights Zurich to London” and it fills in Google Flights and searches.

★ 24,087 GitHub stars · created 2026-09-16 · summarized from the repo README
#3

wheresryan22/anatomy

Who it's for: Teachers, writers and presenters who explain ideas visually.

What it does: A Claude skill (also Codex, OpenCode and others) that turns an idea into an interactive isometric figure (SVG, WebGL, 3D) built from many precise parts.

Example: ask it to explain how an engine works and get an interactive isometric engine.

★ 24,059 GitHub stars · created 2026-10-08 · summarized from the repo README
#4

deepseek-ai/dsh-superagent-prototype

Who it's for: Teams researching autonomous coding agents (the README says it is a research prototype, not an official product).

What it does: A proactive coding agent for one GitHub repo: it listens to GitHub (optionally Feishu), takes work from allowed people, works in its own session and replies in the original thread, e.g. with a PR; a web panel shows what needs a person.

Example: ask it in an issue to fix a bug; it opens a work item and replies with a pull request.

★ 12,603 GitHub stars · created 2026-10-31 · summarized from the repo README
#5

zai-org/ZCode

Who it's for: Developers who want an AI coding workbench (README mainly in Simplified Chinese).

What it does: An AI coding workbench with a desktop app, browser UI and terminal agent; the repo holds the client, backend and agent CLI source.

Example: the start of the README only covers install and build (pnpm bootstrap); no concrete usage example.

★ 8,431 GitHub stars · created 2026-09-20 · summarized from the repo README
#6

Jakeschincariol/replica-skill

Who it's for: Indie developers who want to build and sell an app similar to an existing one.

What it does: Eleven Claude skills: reverse-engineer an app's screens and flows, rebuild, test, plan stack and database, wire auth and payments, brand and launch; it rebuilds features, never code, logos or content.

Example: run /replica-recon in Claude Code to map an app's screens and data model, then hand off to the rebuild skill.

★ 7,128 GitHub stars · created 2026-10-03 · summarized from the repo README
#7

Louis-CFM/coucou

Who it's for: People running AI coding agents on Mac (also Windows, Linux, iPhone, Android).

What it does: A notch buddy: approve permissions, watch agents work, drop files, chat with Claude; v0.4 adds offline voice typing and call recording with transcripts.

Example: away from your desk, an agent's permission request shows on your iPhone Lock Screen and you approve it.

★ 6,902 GitHub stars · created 2026-09-27 · summarized from the repo README
#8

kaankiziltug/logo-design-skill

Who it's for: Founders or designers who need a logo.

What it does: Takes an agent from brief to production SVG files and brand guidelines; includes a 1,400+ reference logo library and Python tools (16 px, one-colour, reversed tests, favicon export).

Example: give it a brand brief and get logo concepts, test sheets and a full favicon set.

★ 5,803 GitHub stars · created 2026-09-26 · summarized from the repo README
#9

Oldcircle/geo-sleuth

Who it's for: Fact-checkers, OSINT researchers, or anyone curious where a photo was taken.

What it does: An agent skill (Claude Code, Codex, Cursor, Gemini CLI, etc.) that infers where a photo was taken and shows its reasoning; its description mentions OpenStreetMap and elevation skylines.

Example: drop in a street photo; it lists clues and a likely location. The README opening does not state accuracy.

★ 5,598 GitHub stars · created 2026-09-18 · summarized from the repo README
#10

wangzan101/Mika

Who it's for: Android 11+ phone users.

What it does: A phone AI assistant: say what you need and it operates apps and the web on a hidden background screen until done, while you keep using your phone.

Example: say “send a message to File Transfer” and it opens WeChat, finds the contact and sends it (README demo).

★ 5,193 GitHub stars · created 2026-10-29 · summarized from the repo README
