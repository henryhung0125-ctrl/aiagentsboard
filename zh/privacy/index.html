隱私權政策

用白話說明我們如何處理你的資料。

簡單說

SI 精選 是一個靜態網站。我們不使用追蹤 Cookie、不放廣告追蹤程式、不使用分析工具，也不販售任何人的資料。

我們會蒐集什麼

瀏覽本站：我們本身不蒐集你的個人資料。託管網站的主機服務商可能會像一般網站一樣，保留標準伺服器紀錄（例如 IP 位址、瀏覽器類型、造訪時間），用於安全與維運。

語言偏好：你切換中文／English 時，瀏覽器會在你自己的裝置上（localStorage）記住選擇。這不是 Cookie，不會傳送給我們，你可以隨時清除瀏覽器資料刪除它。

來信：你寫信給我們時，我們會收到你的電子郵件地址與信件內容，只用來回覆你、處理贊助事宜。

付款：贊助與小額打賞透過 Stripe 付款連結處理。卡號等付款資料由 Stripe 直接處理，我們看不到完整卡號。我們會收到 Stripe 提供的付款紀錄（例如姓名、電子郵件、金額），用於提供服務、開立紀錄與退款。Stripe 如何處理資料請見其 Stripe 隱私權政策。

電子報

訂閱功能尚未上線。上線時我們會更新本頁，說明使用的平台，以及如何隨時取消訂閱。

外部連結

本站連到 GitHub 與各工具網站。離開本站後，適用對方網站的隱私權政策。

保存與你的權利

我們只在需要的期間保留來信與付款紀錄（例如會計或處理爭議所需）。你可以寫信要求查看、更正或刪除我們持有的你的資料：sitop@mail.grokbot.com。

政策變更

若本政策有變更，我們會更新本頁並修改下方的「最後更新」日期。
