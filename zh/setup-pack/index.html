內容

  • context — 可直接放進專案的 AGENTS.md、CLAUDE.md 與 .cursor/rules/*.mdc 範本，涵蓋三種常見技術棧：網頁應用（TypeScript/Next.js）、Python 服務/函式庫、資料分析（Python/SQL/notebook）。
  • prompts — 6 個提示詞範本：規劃、重構、除錯、撰寫測試、程式碼審查、交接筆記，每個都附填好的範例。
  • workflows — 工作流程指南：先規劃再執行、安全的 git 習慣（分支、worktree、禁止 force-push）、子代理與平行代理、上下文管理。
  • checklists — 3 份檢查清單：專案初始設定、每次任務前、合併前。
  • examples — 完整實例：從規劃、分步實作到獨立審查的一次真實流程，以及一份填寫完成的 AGENTS.md。

為什麼比免費範本好用

  • 指令勝過敘述：每份範本都寫出確切的指令（例如 pnpm test -- path），代理照做更可靠。
  • 驗證是任務的一部分：每個提示詞都以「證明它能用」結尾。
  • 明確的禁止清單：不亂加依賴、不改 lockfile、不刪測試、不 force-push。
  • 單一事實來源：AGENTS.md 為主，CLAUDE.md 與 Cursor 規則只引用它，不必維護三份。

# Prompt: Debug from evidence
1. Reproduce the bug first and show me the output.
2. List 2-4 hypotheses ranked by likelihood, with evidence.
3. Test the top hypothesis with the cheapest check. No speculative fixes.
4. Write a failing regression test, then the minimal fix.
Do not: wrap it in try/except, add retries/sleeps as a fix.
