贊助條款

購買贊助前請先閱讀。方案與價格見 贊助頁。

適用範圍

本條款適用於向 SI 精選 購買的所有贊助方案。付款即表示你同意本條款。有任何問題請先寫信給我們：sitop@mail.grokbot.com。

你會得到什麼

每週贊助：為期一週，出現在電子報贊助區塊（電子報上線後）與網站的贊助位置。

上架推廣套組：一週的每週贊助，加上一篇由我們撰寫的中英雙語上架文章。

上架文章（加購）：一篇由我們撰寫的文章，會長期保留在網站上。

價格以付款當下的頁面為準。每售出一檔，後續價格調漲 $25；已付款的訂單不受影響。每週只有一個主贊助位，實際刊登週次由雙方以電子郵件確認。

一律標示為贊助

所有贊助內容都會清楚標示「贊助」。我們不會把付費內容包裝成編輯推薦或排名。

贊助絕不影響排名

榜單排名只依公開訊號（例如 GitHub 星數）與公開的方法產生。付費不能讓工具上榜、提高名次，也不能讓其他工具被移除或降低名次。

審核與拒絕的權利

我們會審核每一位贊助者與其內容，並保留拒絕任何贊助的權利，例如：詐騙或可疑產品、無法驗證的宣稱、違法內容、惡意軟體，或與讀者無關的內容。

你提供的文案、連結與素材必須屬實、你有權使用，且不侵害他人權利。我們可能會要求修改，或為了版面與清楚度做小幅編輯。上架文章由我們撰寫，會依事實呈現，不保證只有正面評價。

付款

款項透過 Stripe 付款連結以美元收取。我們不會儲存你的完整卡片資料。

退款

全額退款：如果我們拒絕你的贊助，或因故無法在約定的期間刊登，我們會全額退款，或在你同意下改期。

刊登前取消：在刊登開始前寫信告知，我們可以改期或退款。

刊登後不退款：贊助位開始刊登後（或上架文章發布後），不提供退款。

我們不保證任何點擊、流量、訂閱或銷售成果。

條款變更

我們可能更新本條款，變更不溯及已付款的訂單。
