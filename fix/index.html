What we can usually fix

FAQ

What should I send?

A link to the repo, or a zip (email the zip if you do not have a link), and a short description of the problem: the error, what you already tried, and which tool you used.

Is my code safe?

We only use your code to look at and fix the issue you sent. We don't use it for anything else. If you ask us to delete it, we will.

What if you can't fix it?

You pay nothing. We'll say so after the free first look, before any payment.

How do I pay?

After we confirm we can fix it, we send you a payment link. There's nothing to pay on this page.
